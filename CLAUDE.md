# CLAUDE.md

## Specs and plans

Write design specs and implementation plans to `docs/specs/`, never to
`docs/superpowers/`. This overrides the superpowers skills' default paths:

- brainstorming: `docs/specs/YYYY-MM-DD-<topic>-design.md`
- writing-plans: `docs/specs/YYYY-MM-DD-<feature-name>-plan.md`

Wherever a superpowers skill names `docs/superpowers/specs/` or
`docs/superpowers/plans/`, read it as `docs/specs/`.
